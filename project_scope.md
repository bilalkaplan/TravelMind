# TravelMind RAG - Project Scope

## Project Type

TravelMind RAG is a local LLM-powered hotel decision assistant.

The project focuses only on hotels and accommodation selection.

## Main Goal

The goal is to help users choose a suitable hotel by analyzing:

- hotel name
- location
- room type
- bed type
- room price
- hotel score
- review count
- room comments
- user preferences

The system will not be a general travel planner. It will only support hotel selection.

## Data Sources

The project uses public Kaggle datasets.

Used datasets:

1. Trip Advisor Hotel Reviews
   - Used for hotel review and rating analysis.

2. Hotel Dataset: Rates, Reviews & Amenities
   - Used for hotel catalog, room price, room type, bed type, score and room comment information.

The data is not generated by us and is not fully synthetic.

## Model Decision

Main LLM:

- Phi-4-mini-instruct

Alternative test model:

- qwen3-0.6b

qwen3-0.6b will not be used in the main application because it shows unnecessary "Thinking..." output and gives weaker Turkish responses.

Phi-4-mini-instruct will be used as the main model.

## Language Policy

The assistant should work in both Turkish and English.

Rules:

- If the user asks in Turkish, answer in Turkish.
- If the user asks in English, answer in English.
- If the hotel data is English but the user asks in Turkish, summarize it in Turkish.
- Do not show thinking or reasoning text to the user.
- Do not invent hotel names, prices, locations or features.
- If the dataset does not contain enough information, say that clearly.

## RAG Workflow

The LLM will not be fine-tuned.

The system will use RAG:

1. Understand the user's hotel preference.
2. Retrieve relevant hotel records and review chunks.
3. Give the retrieved context to Phi-4-mini-instruct.
4. Generate a clear answer.
5. Show source hotel or review IDs.
